## AutoFeeding ↔ AutoProgram ↔ Dobot M1Pro 三重交握協議

### 完整協調流程
```
AutoFeeding(900) ↔ AutoProgram(1300) ↔ Dobot M1Pro(1200)

入料完成交握:
1. AutoFeeding檢測到保護區內CASE_F → 940=1
2. AutoProgram讀取座標到1341-1344 → 945=1確認
3. AutoProgram觸發Dobot M1Pro → 1340=1 (向1240寫入)
4. Dobot M1Pro執行Flow1 → 1204=1完成
5. AutoProgram檢測完成 → 恢復AutoFeeding
```

### 暫停控制交握流程
```
1. AutoProgram需要暫停入料 (Flow1執行前)
2. 寫入921=1 (暫停AutoFeeding)
3. AutoFeeding檢測到暫停信號，停止檢測週期
4. AutoProgram觸發Dobot M1Pro執行Flow1
5. Flow1完成後，AutoProgram寫入921=0
6. AutoFeeding恢復檢測週期
```
